Support

If you need help with Project Delivered, please contact the app developer using the support email address you publish for the app.

Common support topics

  • Sign-in or account-access issues
  • Profile and account settings
  • Direct and group conversations
  • Photo, file and voice-message sharing
  • Notifications, privacy settings and read receipts
  • Password, PIN and biometric access
  • Account deletion

Before contacting support

Please include a short description of the issue, the device model you are using, and the version of iOS installed. Do not include your password, PIN or other secret credentials.
